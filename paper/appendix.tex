\section{Formal Mathematical Proofs}
\label{app:proofs}

\subsection{Generalization of Proposition 1: Newman Modularity Upper Bound for Arbitrary $K$-Community Partitions}
\label{app:proof_modularity}

In Section~\ref{sec:theory}, Proposition~\ref{prop:modularity} established that for any undirected network symmetrically partitioned into $K=2$ communities, the Newman modularity satisfies $Q \leq 0.500$. Here we provide the complete general proof for an arbitrary number of communities $K \geq 2$.

\begin{theorem}[Universal Modularity Upper Bound for $K$ Communities]
\label{thm:general_modularity}
Let $\mathcal{G} = (\mathcal{V}, \mathcal{E})$ be an undirected graph with $m = |\mathcal{E}|$ edges, partitioned into $K \geq 2$ non-empty disjoint communities $\mathcal{V}_1, \dots, \mathcal{V}_K$. Let $\mathrm{vol}(\mathcal{V}_c) = \sum_{i \in \mathcal{V}_c} d_i$ denote the degree volume of community $c$. Then:
\begin{equation}
    Q \leq 1 - \sum_{c=1}^K \left( \frac{\mathrm{vol}(\mathcal{V}_c)}{2m} \right)^2 \leq 1 - \frac{1}{K}.
\end{equation}
Equality $Q = 1 - 1/K$ holds if and only if the network has zero cross-community edges and all communities possess identical degree volumes: $\mathrm{vol}(\mathcal{V}_1) = \dots = \mathrm{vol}(\mathcal{V}_K) = 2m/K$.
\end{theorem}

\begin{proof}
By Newman's definition \citep{newman2006modularity}, modularity is formulated as:
\begin{equation}
    Q = \sum_{c=1}^K \left[ \frac{e_{cc}}{2m} - a_c^2 \right],
\end{equation}
where $e_{cc} = \sum_{u, v \in \mathcal{V}_c} A_{uv}$ denotes the total adjacency weight internal to community $\mathcal{V}_c$, and $a_c = \frac{\mathrm{vol}(\mathcal{V}_c)}{2m}$ satisfies $\sum_{c=1}^K a_c = 1$ with $a_c > 0$.

First, let $e_{cc'} = \sum_{u \in \mathcal{V}_c, v \in \mathcal{V}_{c'}} A_{uv}$ denote the total directed cross-community adjacency weight between communities $c$ and $c'$. Total weight conservation across the graph gives $\sum_{c=1}^K e_{cc} + \sum_{c \neq c'} e_{cc'} = 2m$. Dividing by $2m$:
\begin{equation}
    \sum_{c=1}^K \frac{e_{cc}}{2m} = 1 - \sum_{c \neq c'} \frac{e_{cc'}}{2m} \leq 1,
\end{equation}
with equality holding if and only if the graph is completely disjoint across communities (i.e., cross-community weight $e_{cc'} = 0$ for all $c \neq c'$).

Second, consider the negative quadratic term $\sum_{c=1}^K a_c^2$. By the Cauchy-Schwarz inequality applied to vectors $\mathbf{a} = (a_1, \dots, a_K)^\top$ and $\mathbf{1} = (1, \dots, 1)^\top$:
\begin{equation}
    \left( \sum_{c=1}^K a_c \right)^2 \leq \left( \sum_{c=1}^K 1^2 \right) \left( \sum_{c=1}^K a_c^2 \right) \implies 1^2 \leq K \sum_{c=1}^K a_c^2.
\end{equation}
Thus, we obtain the strictly enforced lower bound:
\begin{equation}
    \sum_{c=1}^K a_c^2 \geq \frac{1}{K},
\end{equation}
with equality if and only if $a_1 = a_2 = \dots = a_K = 1/K$. Combining these two inequalities:
\begin{equation}
    Q = \sum_{c=1}^K \frac{e_{cc}}{2m} - \sum_{c=1}^K a_c^2 \leq 1 - \frac{1}{K}.
\end{equation}
For $K=2$ (bipolar polarization), $Q \leq 1 - 1/2 = 0.500$. For $K=4$ (e.g., the four distinct sub-forums in Reddit ConvoKit), $Q \leq 1 - 1/4 = 0.750$. This mathematically explains why experimental modularity on Reddit saturates around $Q \approx 0.654 \sim 0.735$, whereas bipolar networks strictly cap at $0.500$.
\end{proof}

\subsection{Detailed Derivation of Proposition 2: Positive Lebesgue Measure of Asymmetric Rupture Polytope}
\label{app:proof_polytope}

\begin{proof}
Consider two agents $i$ and $j$ in a $d$-dimensional continuous ideological space with states $\mathbf{b}_i, \mathbf{b}_j \in [-1, 1]^d$. Each agent assigns attention weight vector $\mathbf{w}_i = (w_{i,1}, \dots, w_{i,d})^\top$ satisfying $\sum_{k=1}^d w_{i,k} = 1$ with $w_{i,k} > 0$. The perceived ideological distance evaluated by agent $i$ towards agent $j$ is:
\begin{equation}
    \mathcal{D}_i(\mathbf{b}_i, \mathbf{b}_j) = \sum_{k=1}^d w_{i,k} |b_{i,k} - b_{j,k}|.
\end{equation}
Let $\Theta_i$ and $\Theta_j$ be the respective severance thresholds. The set of configuration pairs $(\mathbf{b}_i, \mathbf{b}_j) \in [-1, 1]^{2d}$ under which agent $i$ severs the directed link $(i, j)$ while agent $j$ preserves $(j, i)$ is:
\begin{equation}
    \Omega_{\mathrm{asym}} = \left\{ (\mathbf{b}_i, \mathbf{b}_j) \in [-1, 1]^{2d} \;\middle|\;
    \begin{aligned}
        \textstyle\sum_{k=1}^d w_{i,k} |b_{i,k} - b_{j,k}| > \Theta_i \;\land \\
        \textstyle\sum_{k=1}^d w_{j,k} |b_{j,k} - b_{i,k}| \leq \Theta_j
    \end{aligned}
    \right\}.
\end{equation}
Let $\Delta_k = |b_{i,k} - b_{j,k}| \in [0, 2]$. Rewriting the conditions in terms of difference vector $\boldsymbol{\Delta} = (\Delta_1, \dots, \Delta_d)^\top$:
\begin{equation}
    \mathbf{w}_i^\top \boldsymbol{\Delta} > \Theta_i \quad \text{and} \quad \mathbf{w}_j^\top \boldsymbol{\Delta} \leq \Theta_j.
\end{equation}
Whenever the weight vectors $\mathbf{w}_i$ and $\mathbf{w}_j$ are non-collinear (which occurs almost everywhere under heterogeneous archetypes), the two hyperplanes $H_i = \{\boldsymbol{\Delta} \mid \mathbf{w}_i^\top \boldsymbol{\Delta} = \Theta_i\}$ and $H_j = \{\boldsymbol{\Delta} \mid \mathbf{w}_j^\top \boldsymbol{\Delta} = \Theta_j\}$ intersect transversally. 

For $d \geq 2$, the region bounded between these two non-parallel hyperplanes in the positive orthant $[0, 2]^d$ contains an open ball $B(\boldsymbol{\Delta}_0, \epsilon)$ with radius $\epsilon > 0$. Since the mapping $(\mathbf{b}_i, \mathbf{b}_j) \mapsto \boldsymbol{\Delta}$ is a surjective piecewise-linear submersion with full rank $d$, the pre-image $\Omega_{\mathrm{asym}}$ contains an open non-empty set in $\mathbb{R}^{2d}$. Therefore, the Lebesgue measure $\mu(\Omega_{\mathrm{asym}}) > 0$.
\end{proof}

\subsection{The Multi-Dimensional Update Kernel}
\label{app:kernel}

Section~\ref{sec:theory-update} states the multi-dimensional cognitive kernel of the semantic
arm in prose, because the flagship engine does not use it. For completeness we write it
out. When listener $i$ observes statement $\mathbf{s}_j(t)$ emitted by speaker $j$, the
perceived ideological distance is the salience-weighted metric
\begin{equation}
    \delta_{ij}(t) = \sum_{k=1}^{d} w_{i,k} \, |b_{i,k}(t) - b_{j,k}(t)| \in [0, 2],
    \label{eq:dissonance}
\end{equation}
where $\mathbf{w}_i$ is the attention-weight profile of agent $i$ over the $d$ issue
dimensions, and the belief vector moves toward the speaker with damping $\eta \in (0, 1]$:
\begin{equation}
    \mathbf{b}_i(t+1) = \mathbf{b}_i(t) + \eta \cdot \psi(\delta_{ij}(t), \theta_i) \cdot (\mathbf{s}_j(t) - \mathbf{b}_i(t)),
    \label{eq:kernel-update}
\end{equation}
with the cognitive reaction kernel of Equation~\ref{eq:kernel}
\begin{equation}
    \psi(\delta, \theta) =
    \begin{cases}
        1 - \delta / 2, & \delta \leq \theta, \\
        -\beta (\delta - \theta), & \theta < \delta \leq \theta_{\mathrm{block}}, \\
        0, & \delta > \theta_{\mathrm{block}} .
    \end{cases}
    \label{eq:kernel}
\end{equation}
The anisotropy of $\mathbf{w}_i$ across agents is the mechanism isolated in
Section~\ref{sec:attribution}: it is what allows two agents with the \emph{same} belief
coordinates to break ties in opposite directions. The scalar flagship engine instead
uses Equation~\eqref{eq:scalar-update}; the two must not be conflated. The damping
coefficient $\eta$ of Equation~\ref{eq:kernel-update} and the backfire slope $\beta$ are
listed with all other hyper-parameters in Table~\ref{tab:hyperparameters}.

\paragraph{Provenance: real data versus surrogate proxies.}
Only \textbf{SNAP Higgs Twitter (REAL public data)} is derived from a public dataset --- the
Stanford SNAP \texttt{higgs-social\_network} edge list (456{,}626 nodes / 14{,}855{,}842 directed
edges, SHA256 \texttt{8e5ea764\ldots 40265}), from which seeded high-degree induced subgraphs are
derived; its URL, checksum and derivation recipe are recorded in \texttt{data/raw/README.md}. Its
ideology prior is \emph{topology-derived} (the two largest Louvain communities \citep{blondel2008fast} of the induced
subgraph are read as two camps, with a seeded jitter on top) and is therefore a \textbf{structural
proxy variable}, \emph{not} a human-annotated stance label; the Higgs data contains no political
annotation of any kind. The remaining five networks are \textbf{synthetic surrogates} that
reproduce the qualitative topology of their reference sources (dense bipartite debate clusters,
scale-free hub/bridger/long-tail structure, four forum sub-communities, bipartite rater graphs).
They are calibrated proxies, and are labelled as such wherever they appear.

\paragraph{Third-party assets, licenses and redistribution policy.}
The study uses exactly one third-party asset: the SNAP \texttt{higgs-social\_network} edge list,
distributed by the Stanford SNAP repository under the SNAP dataset terms of use (free for
research use; the collection is documented in the accompanying JNLP paper \citep{domenico2013anatomy}).
We \emph{do not redistribute} it: the raw file is excluded from version control, only its SHA-256
is published, and the derived artifacts we release are (i) seeded induced subgraphs that preserve
only integer node identifiers and edge directions, and (ii) aggregate statistics. The file contains
no message text, no user handles, no attributes and no content of any kind --- only pseudonymous
integer node ids and directed edges --- so it carries no directly identifying information and no
offensive content. Every baseline framework we implement (DeGroot, Hegselmann--Krause,
Friedkin--Johnsen, generative agents, prompt-driven rewiring) is re-implemented from its original
publication rather than copied, and is cited in Section~\ref{sec:related}; the code and the new
artifacts we release (frozen result files, generated tables and macros, provenance manifest, LLM
call archive) are published under a permissive open-source license.

\paragraph{Ideology spaces of the surrogate generators.}
The DEBATE surrogate samples beliefs from the published human-prior mean and standard deviation of
the NeurIPS 2024 DEBATE benchmark; the Twitter 2020 surrogate uses a bipolar DW-NOMINATE-style
prior; the Reddit surrogate assigns each node to one of four forum sub-communities with a
three-dimensional topic vector (economic / social / geopolitical), of which the benchmark uses the
first coordinate as the scalar prior; the Birdwatch surrogate uses a two-pole rater structure; the
SNAP-Higgs surrogate uses a Gaussian two-pole prior. In all cases the surrogate topology and the
surrogate belief prior are generated by the same seeded process, so these datasets must not be
cited as evidence about the corresponding real-world platforms --- they are controlled
environments whose qualitative structure is inspired by those platforms.

\section{Exhaustive Numerical Audit of the Generalised Modularity Bound}
\label{app:bound-audit}

The generalized bound of Proposition~\ref{prop:modularity} makes a falsifiable prediction
for every cell of the benchmark matrix: the reported $Q$ must not exceed $1-1/K$ for the
realized community count $K$. We verify this exhaustively over all \AuditCellsChecked{}
(dataset $\times$ method) cells and over the \HOneGridCount{}-configuration evolution grid.
The audit reports \AuditViolations{} violations, and the realized community counts span
$K=2$ (bipolar surrogates), $K \in \{3,4,5\}$ (multi-community surrogates) and
$K \in \{8,9\}$ (the empirical SNAP Higgs subgraph). Every high-modularity cell in
Table~\ref{tab:sota_matrix} --- for instance $Q=0.735$ on Reddit ConvoKit under
Hegselmann--Krause --- is therefore fully consistent with the theory: it corresponds to a
realized $K=4$ partition whose bound is $0.750$, not to a violation of a universal $0.500$
cap. This closes the contradiction between the theory and the benchmark matrix that the
earlier version of this manuscript left open.

The audit is generated by \texttt{scripts/generate\_paper\_tables.py} directly from
\texttt{results/phase5\_bound\_audit.json} and \texttt{results/sota\_benchmark.json}; the
machine-readable violation list is stored in the bound-audit result file rather than
transcribed here, so the claim ``\AuditViolations{} violations'' is reproducible rather
than asserted.

\section{Cross-Topology Critical Tolerance: All Three Criteria}
\label{app:threshold}

Section~\ref{sec:findings} reports that the previously claimed topology-invariant critical
tolerance does not survive re-measurement. We give the full accounting here, including the
per-criterion censoring, so that the negative result can be inspected rather than taken on
trust.

\paragraph{Connectivity-recovery criterion ($\theta^*_{\mathrm{frag}}$).} The smallest
tolerance at which the giant component is restored to $\geq 0.99$. Of the
\ThresholdFragEstimates{} seed-level estimates, \ThresholdFragInBand{} fall inside the
originally asserted band $[\ThresholdBandLow, \ThresholdBandHigh]$. The per-topology
estimates are \ThresholdFragErdosRenyi{} (Erd\H{o}s--R\'enyi), \ThresholdFragScaleFree{}
(Barab\'asi--Albert), \ThresholdFragSmallWorld{} (Watts--Strogatz) and
\ThresholdFragEmpiricalBipolar{} (empirical bipolar), a cross-topology spread of
\ThresholdFragSpread.

\paragraph{Modularity-collapse criterion ($\theta^*_Q$).} Only \ThresholdQInBand{} of
\ThresholdQEstimates{} estimates fall in the asserted band, and the estimate is
right-censored for \ThresholdQCensoredErdosRenyi{} (ER),
\ThresholdQCensoredScaleFree{} (scale-free),
\ThresholdQCensoredSmallWorld{} (small-world) and
\ThresholdQCensoredEmpiricalBipolar{} (empirical bipolar) of \ThresholdSeeds{} seeds.
Censoring happens because residual community structure keeps modularity above the collapse
level even after the giant component has shattered, so no threshold satisfies the
criterion within the grid. This is why we treat the modularity-collapse criterion as
ill-suited to the question rather than as a competing answer to it.

\paragraph{Polarization-collapse criterion ($\theta^*_{\Pi}$).} Only \ThresholdPolInBand{}
of \ThresholdPolEstimates{} estimates fall in the asserted band, with a per-topology spread
of \ThresholdPolSpread.

\paragraph{Structural control.} Homogeneous baseline networks devoid of Bridgers split into
completely isolated subgraphs ($\text{Giant Component Fraction} = \PhaseOneHomoGiant$,
cross-edges $= \PhaseOneHomoCross$), whereas heterogeneous archetype graphs maintain
global weak reachability ($\text{Giant Frac} = \PhaseOneHeteroGiant$, cross-edges $= \PhaseOneHeteroCross$).

We therefore report all three criteria with their censoring counts rather than a single
preferred number, and we make no claim that the critical tolerance is a topology-independent
constant. Furthermore, attributing cross-graph variation solely to macroscopic topology is
complicated by initial density and reciprocity confounds (though lower-bound left-censoring is completely eliminated, \ThresholdFragLeftCensoredFrac, on the extended grid $[\ThresholdGridMin, \ThresholdGridMax]$).

\section{Limitations, in Full}
\label{app:limitations}

Six limitations are material.

\begin{enumerate}
    \item \textbf{Surrogate benchmarks.} Five of the six benchmark networks are
    \emph{surrogate} calibrations of published statistics rather than the published datasets
    themselves; only \textsc{SNAP Higgs (REAL)} uses an unmodified public edge list, and even
    there the camps are topology-derived proxies because the file carries no stance labels.
    \item \textbf{Scale of the real-LLM arms.} The historical Phase~2 arm remains small
    (\LlmSeeds{} seeds, \LlmPairs{} dyadic decisions, \LlmCalls{} batched API calls) and its
    responses lack a full execution receipt (model identifier and token accounting) in the
    archived artifacts. The receipt-complete Phase~6 arm (\LlmArmSeeds{} seeds,
    \LlmArmDecidedEvents{} LLM-decided interactions, \LlmArmApiCalls{} API calls with full
    token accounting) is larger, but its \emph{interaction coverage} is only
    \LlmArmCoverage{}, yielding an estimated difference of $\Delta Q \in [\LlmArmQCILow, \LlmArmQCIHigh]$
    (95\% CI; paired $A_{\mathrm{rupture}}$ differences exhibit zero sample variance across all 10 seeds),
    which bounds the effect size any such arm can detect.
    \item \textbf{Scope of the attribution ablation.} The ablation spans $d \in \{1,3\}$ and
    a 10-arm factorial combination of synchronous, asynchronous uniform-speaker, and
    asynchronous weighted-speaker schedules. The results demonstrate that asynchronous
    scheduling artifacts arise from pure temporal timing rather than speaker frequency bias
    ($\Delta A = \SpeakerBiasEffect$, $p = \SpeakerBiasEffectP$), and that scheduling and semantic
    anisotropy exhibit sub-additive saturation rather than independent additivity
    ($\Delta A = \ScheduleEffectMultidimPure$, $p = \ScheduleEffectMultidimPureP$).
    \item \textbf{Resolution of the reach metric.} The reach metric is a seeded
    independent-cascade estimate whose variance across seeds is large relative to the policy
    effects we report, which limits the resolution of RQ3.
    \item \textbf{Synchronous-evaluation caveat.} The original claim that scalar models cannot
    produce asymmetric rupture is only valid under synchronous evaluation; we have quantified
    the asynchronous contribution rather than removed it.
    \item \textbf{Criterion dependence.} The critical-tolerance estimate is
    \emph{criterion-dependent} and entangled with initial density and reciprocity: the
    connectivity-recovery criterion ($\theta^*_{\mathrm{frag}}$) and the
    polarization-collapse criterion ($\theta^*_{\Pi}$) disagree, and the modularity-collapse
    criterion is right-censored for
    \ThresholdQCensoredSmallWorld{}/\ThresholdQCensoredEmpiricalBipolar{} of
    \ThresholdSeeds{} seeds in the small-world and empirical-bipolar topologies because
    residual community structure keeps modularity above the collapse level, though
    lower-bound left-censoring is completely eliminated (\ThresholdFragLeftCensoredFrac{} on
    the $[\ThresholdGridMin, \ThresholdGridMax]$ grid, minimum observed $\theta^*_{\mathrm{frag}}=\ThresholdFragMin$).
\end{enumerate}

All software, benchmark loaders, cached real-data subgraphs, figure scripts, and
auto-generated tables are provided in our open-source release.

\section{Ethics: Misuse Channels and Mitigations}
\label{app:ethics}

This research models opinion dynamics and platform intervention mechanisms on public social
networks. All benchmark networks are either derived from publicly accessible academic
archives or are explicitly labelled synthetic structural surrogates; the one empirical
network uses the publicly released, anonymized SNAP Higgs edge list, and no private
communications, credentials, or personally identifiable content were collected,
intercepted, or re-identified. The real-data subgraph retains only integer node identifiers
and edge directions. Research findings on platform interventions are presented to foster
scientific understanding of algorithmic diversity and depolarizing platform governance.

Three specific misuse and harm channels deserve naming.

\begin{enumerate}
    \item \textbf{Asymmetric rupture as a polarization recipe.} A validated account of
    \emph{asymmetric rupture} is a recipe for making polarization faster and less visible:
    an actor who can sever one side of a reciprocal tie without reciprocal severance can
    polarize a community while every public graph metric still looks healthy.
    \item \textbf{Efficiency results read as prescriptions.} The counterfactual platform
    policies are efficiency results, not prescriptions --- our own policy arms show that all
    tested individual interventions fail the pre-specified conjunction threshold, and a reader who treats
    the partial modularity reduction as a prescription would be over-reading the evidence.
    \item \textbf{Surrogates cited as populations.} The surrogate benchmarks are calibrated to
    published statistics but are \emph{not} the datasets they are named after; citing them as
    measurements of any real population would be a category error.
\end{enumerate}

Mitigations are concrete rather than aspirational: every run is seeded and auditable, the
raw public edge list is excluded from version control and published only as a hash, the real
network's ideology variable is labelled a topology-derived proxy, and the raw LLM call
archive makes the LLM arm replayable without further API spend.

\section{Agent Prompts and LLM Semantic Interaction Schemas}
\label{app:prompts}

To validate micro-cognitive fidelity under real foundation models, agents in Phase 2 query the API backend using standardized prompt contracts. The prompt instructs the model to act as a listener with personal multi-dimensional stances evaluating an incoming peer statement.

\subsection{Prompt Specification Template}
\begin{quote}
\small
\texttt{System: You are an autonomous agent in a social network simulation. You hold personal stances on 3 continuous political/technical issues in range [-1.0, 1.0]:}\\
\texttt{- Dimension 1: Government AI Safety Regulation (Pro-Safety: +1.0 vs Pro-Innovation: -1.0)}\\
\texttt{- Dimension 2: Privacy and Encryption Backdoors (Pro-Privacy: +1.0 vs Law Enforcement: -1.0)}\\
\texttt{- Dimension 3: Frontier Model Open Weights (Pro-Open: +1.0 vs Pro-Closed: -1.0)}\\
\texttt{Your current belief vector: [\{b1\}, \{b2\}, \{b3\}]. Your tolerance threshold is \{theta\}.}\\
\texttt{You observe the following statement from speaker \{speaker\_id\}: "\{statement\}".}\\
\texttt{Output strict JSON with format:}\\
\texttt{\{ "cognitive\_dissonance": float [0.0, 2.0], "belief\_shift": [float, float, float], "relationship\_action": "reinforce" | "decay" | "unfollow" | "block", "reasoning": "brief string" \}}
\end{quote}

\subsection{API Cost Ledger and Token Accounting}
All API requests were executed with batching ($K_{\mathrm{events}}=12$ per dispatch) and semantic caching. The archived execution receipts in \texttt{data/llm/seed*/final.json} record:
\begin{itemize}
    \item Total batched API calls executed: \LlmCalls{} (covering \LlmPairs{} dyadic interaction evaluations across \LlmSeeds{} seeds).
    \item Budget ceiling pre-specified: 100 API calls. Actual consumption: \LlmCalls\% of budget.
    \item Each dyadic decision was logged with the listener profile, the observed statement, the returned belief vector, the relationship action and a natural-language rationale.
\end{itemize}
\paragraph{Disclosed receipt gap for the historical arm, and how it is closed.}
The \emph{historical} Phase~2 artifacts (\texttt{data/llm/seed*/final.json}) record the number of calls, the number of validated responses and the semantic-hash cache behaviour, but \emph{not} the model identifier, sampling temperature, or per-call token counts. That arm therefore cannot be re-executed bit-for-bit against a pinned model, and the paper makes no claim that depends on those fields; we report it as \emph{qualitative semantic evidence} (decision rationales such as ``disagree strongly on regulation, but we agree on open-source'').

The gap is closed for all new work by the unified backend of Section~\ref{sec:llm-arm}: every call now writes a content-addressed receipt recording the model identifier, the temperature, the input/output/thinking token counts, the provider response identifier and the stop reason, plus the parse-success rate and the action distribution (Table~\ref{tab:llm_arm}). Because the archive is keyed by a hash of the full request, a re-run of the same experiment produces \emph{zero} API calls and a bit-identical result, which is a strictly stronger reproducibility property than a fresh call with a possibly different model version. The one thing that remains unrecoverable is the identity of the model that produced the \emph{historical} artifacts, and we state that limitation rather than guessing it.
