# 标注任务说明（中文版）

感谢你参与。你要判断 300 条简短事件，每条是一个隐藏模型在社交网络模拟中做出的关系动作。

## 你需要哪些文件

- `annotation_sheet_zh.csv`：300 条待标注事件；
- `codebook_zh.md`：判定规则和例子，请先读。

**不要索要或使用 `annotation_key.csv`**。这个文件只给研究团队，里面含模型身份和模型推理，看到会引入偏差。

## 你要填什么

每条只填以下四列：

1. `动作是否合理`：填 **合理 / 不合理 / 无法判断**；
2. `你会选择的动作`：填 **保持 / 静音 / 取关 / 拉黑**；
3. `把握程度1到5`：填 1–5；
4. `备注`：可选，尤其是“无法判断”时请写原因。

只能使用上面这些词；前两列不能空。不要改其它列。

## 独立性要求

- 独自完成，不要和另一位标注者逐条讨论。
- 不要试图识别模型或猜测论文结论。
- 判断“这个动作是否合理”，不是“我是否会这样做”；不同但合理的动作也算合理。
- 建议先做 20 条 pilot，再开始全量；每 45–60 分钟休息一次。

## 返回文件

保存为：

- `annotation_sheet_zh_标注者A.csv`
- `annotation_sheet_zh_标注者B.csv`

不要改行顺序，不要改事件编号。把填好的 CSV 交回研究团队。
