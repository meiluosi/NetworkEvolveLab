# 第二套规则：预填审校说明（中文）

这份表是第二套外包规则生成的**预填草稿**，用于人工逐条复核。样本是新的 300 条，与第一套 300 条不重复。

## 规则摘要

a = 听众，b = 对方。

- **a 中立，b 对立**
  - b 强烈：90% 取关，10% 静音；
  - b 中等/弱：静音。
- **a 中等，b 对立**
  - b 强烈：拉黑；
  - b 中等：取关；
  - b 弱/中立：静音。
- **a 强烈，b 对立**
  - 不立即拉黑，先争论（保持/静音），最终拉黑；
  - 预填动作：保持 50%、静音 30%、拉黑 20%；
  - 合理集合：保持/静音/拉黑。
- **同阵营**
  - a 强烈：保持；
  - 其他：基本静音。
- **双方中立**：保持。

预填的“动作是否合理”是基于模型动作是否落在该规则允许集合内；“你会选择的动作”是规则采样出的参考动作。  
**预填只是参考，请逐条独立判断；不同意就直接改。**

## 你需要做什么

每条只需要复核/修改：

- `动作是否合理`：合理 / 不合理 / 无法判断；
- `你会选择的动作`：保持 / 静音 / 取关 / 拉黑；
- `把握程度1到5`；
- `备注`：修改时写原因。

不要改：事件编号、听众类型、听众立场、听众立场描述、对方发言、关系强度、模型动作、预填说明。

不要改行顺序，不要改事件编号。
