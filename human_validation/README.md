# Human validation package (300 events)

This folder contains the blind annotation package. **Do not send
`annotation_key.csv` to annotators** — it reveals the source model and model
reasoning. The key is only for analysis after both sheets are returned.

## Files

- **Chinese package:** `outsourcing_package_zh.zip` — send this to Chinese-speaking annotators.
- `annotation_sheet.csv` — 300 blind rows; send this to each annotator (English).
- `annotation_key.csv` — source model / action / reasoning / receipt path; analysis only.
- `codebook.md` — instructions and examples; send with the sheet.
- `../scripts/score_human_validation.py` — computes agreement after annotation.

## Outsourcing protocol

1. Send each annotator **only** `annotation_sheet.csv` + `codebook.md`.
2. Ask them to save as `annotation_sheet_annotatorA.csv` and
   `annotation_sheet_annotatorB.csv` (same rows, same order preferred).
3. They fill only these columns:
   - `is_action_reasonable` in {reasonable, unreasonable, cannot_judge}
   - `preferred_action` in {keep, mute, unfollow, block}
   - `confidence_1_5` in {1,2,3,4,5}
   - `comments` optional
4. Annotators must not see `annotation_key.csv` or the paper's hypothesis.
5. Return both CSVs; run:

```bash
python scripts/score_human_validation.py \
  --a human_validation/annotation_sheet_annotatorA.csv \
  --b human_validation/annotation_sheet_annotatorB.csv \
  --key human_validation/annotation_key.csv \
  --out human_validation/human_validation_report
```

## Sampling

- 150 events from MiniMax-M3, 150 from DeepSeek-flash (both 60-event arms).
- Per model: 75 non-keep decisions (mute/unfollow/block) + 75 random keeps.
- Order shuffled; IDs anonymised; model identity hidden.
- Generated by `scripts/build_human_validation_sample.py` (seed 20261022).

## What the report gives

- Inter-annotator agreement on reasonable/unreasonable (Cohen's κ).
- Inter-annotator agreement on preferred action (Cohen's κ).
- Human-vs-model action agreement.
- Reasonableness rate by source model and by model action.
- Counts of unusable rows; no silent drops.

The paper must state whether annotations were independent or author-coded, and
must not present this package as a result until both sheets are returned.
