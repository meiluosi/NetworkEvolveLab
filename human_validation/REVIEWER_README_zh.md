# 预填表审校说明（中文版）

这份表已经按你们提供的规则生成了**预填草稿**。你的任务不是接受它，而是**逐条独立审校**：同意就保留，不同意就修改，并在备注里写原因。

## 重要

- 预填只是草稿，不是标准答案，也不是模型输出。
- 不要因为“已经填了”就默认接受；每一条都要重新判断。
- 不要看 `annotation_key.csv`，它含模型身份和模型推理。
- 不要和另一位审校者逐条讨论；两份表交回后再处理分歧。
- 预填会带来锚定效应，所以研究团队会在论文中写明这是“human-reviewed rule-prefilled audit”，不会写成完全独立的人工标注。

## 你需要复核的列

- **动作是否合理**：可保留 `合理/不合理`，或改成 `无法判断`。
- **你会选择的动作**：可保留 `保持/静音/取关/拉黑`，或改成你认为更合适的动作。
- **把握程度1到5**：可保留或修改。
- **备注**：如果修改了前两列，请简单写原因；尤其是改成“无法判断”时。
- **预填说明**：只读，不要修改。

不要改：事件编号、听众类型、听众立场、听众立场描述、对方发言、关系强度、模型动作。

## 返回

保存为：

- `annotation_sheet_zh_审校者A.csv`
- `annotation_sheet_zh_审校者B.csv`

不要改行顺序，不要改事件编号，不要新增/删除行。

## 评分方式

研究团队会用 `scripts/score_human_validation.py` 计算：

- 两位审校者之间“是否合理”的 Cohen's κ；
- 两位审校者“会选择动作”的 κ；
- 审校后 vs 模型动作一致率；
- 按模型、按规则类别的合理率；
- 分歧行和不可用行。

如果只有一位审校者，则不计算 inter-annotator κ，只报告“单审校者 human-reviewed rule-prefilled audit”。
