# 人工标注说明（中文版 v1）

你要做的是：**逐条判断一个模型在社交网络模拟中的关系动作是否合理**。  
你看不到模型名字，也看不到论文假设。没有唯一“标准答案”，请按本说明保持一致。

## 每条你能看到什么

| 列名 | 含义 |
|---|---|
| 事件编号 | 匿名事件编号，不要修改 |
| 听众类型 | 枢纽型（hub）/ 桥梁型（bridger）/ 长尾型（tail） |
| 听众立场 | 听众对该议题的立场，范围 -1 到 +1；负数偏反对，正数偏支持 |
| 听众立场描述 | 把听众立场转成一句自然语言 |
| 对方发言 | 对方（speaker）对听众说的话 |
| 关系强度 | 当前这条关注关系的强度，0 到 1 |
| 模型动作 | 模型选择的关系动作（保持/静音/取关/拉黑） |

## 四个动作的含义

- **保持（keep）**：继续维持当前关注关系，正常接触。
- **静音（mute）**：保留关系，但降低对对方的关注/曝光。
- **取关（unfollow）**：断开这条有向关注关系，以后不再关注对方。
- **拉黑（block）**：断开关系并拉黑对方。

## 问题 1：这个动作是否合理？

在“动作是否合理”列填以下三个值之一：

- **合理**：在这个听众状态下，一个理性的 agent 有可能做出这个动作。
- **不合理**：这个动作明显违背听众立场、对方发言或关系价值。
- **无法判断**：事件信息自相矛盾，或太模糊，无法判断。

注意：“合理”不等于“我会选这个动作”。一个不同但站得住脚的动作，仍然算合理。

## 问题 2：如果由你决定，你会选什么？

在“你会选择的动作”列填以下四个值之一：

- 保持
- 静音
- 取关
- 拉黑

这是你的偏好动作，不是让你猜模型会选什么。

## 问题 3：把握程度

在“把握程度1到5”列填 1–5：

- 1 = 非常不确定
- 3 = 一般
- 5 = 非常确定

## 例子

1. 听众立场 +0.72，对方发言也强烈支持（+0.68），关系强度 0.9：  
   保持 = 合理；静音 = 可以辩护但偏保守；取关 = 不合理，因为双方立场接近且关系强。

2. 听众立场 -0.65，对方强烈支持（+0.70），关系强度 0.2：  
   取关或静音 = 合理；保持 = 较弱，除非听众是特别宽容的桥梁型。

3. 听众立场 0（中立），对方也中立，关系强度 0.8：  
   保持 = 合理；没有额外信息时，取关很难辩护。

## 填写规则

- 300 行都要填；“动作是否合理”和“你会选择的动作”不能空。
- 只能使用上面给出的中文词，不要自创词。
- 不要修改“事件编号、听众类型、听众立场、听众立场描述、对方发言、关系强度、模型动作”这些列。
- 不要搜索模型名字，不要讨论论文假设。
- 独立完成；两人不要逐条讨论，等两份表都交回后再由研究方处理分歧。
- 如果某条你之前见过，也请重新独立判断。

## 建议节奏

每条约 30–60 秒；300 条约 3–5 小时。建议每 45–60 分钟休息一次。  
正式开始前先做 20 条 pilot，确认理解一致再继续。
